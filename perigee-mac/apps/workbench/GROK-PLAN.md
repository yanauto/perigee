# Perigee → Grok 桌面（施工批次）

产品名仍叫 Perigee。做的是：本机 Grok 写代码/干活的窗。不仿官方 Grok Bot，不复刻 grok.com。

现在：新壳是 Cursor 网页空壳，对话是假引擎。旧桌面（`apps/desktop`）已有真 Grok（ACP）。本轮改新壳，旧桌面先不动。

## 留下 / 拿掉

留下：智能体首页、对话、模型与钥匙、侧栏会话。自动化先留入口，第 5 批再接真定时任务。

拿掉（不当默认路径）：欢迎宣传、邮箱验证、下载客户端、账单/用量/套餐、Teams、Bugbot、云端 VM、插件市场、假 Slack/GitHub。文件可先藏，不必第一批物理删光。

进门：本机已有 Grok CLI / 用户目录里的 Grok 配置 → 直接进首页；没有 → 只留「模型与钥匙」一页。

## 第 1 批 · 变成本机 App

打开就是首页，不再走登录进门。侧栏只留新对话 / 对话列表 / 自动化 / 模型与钥匙。

验收：`workbench up` 后当前页是 `agents-home`；不需要 `enter` 邮箱；`pages` 不再把公司页当主路径；隐藏窗自拍首页不是欢迎页。

## 第 2 批 · 真开口

假引擎换成旧桌面那条 Grok ACP。`send` 真回。没有 CLI 时诚实提示，不要假成功。

验收：本机有 Grok 时，`send "你好"` 不是「假引擎」那句；工具行能上屏。没有 Grok 时，钥匙页说清楚缺什么。

## 第 3 批 · 会话像真的

多会话、未读、后台还在跑、取消这一轮。写盘要能问一声。

验收：开两个会话，一个在回时切到另一个，侧栏能看出谁在干活。

## 第 4 批 · 浏览器和文档

接 Flyby：agent 能开页、能读。文档边写边渲染。测可以用 Chrome（隔离浏览器或已登录的 Chrome），不要抢用户正在用的前台窗。

验收：发一条「打开某页读标题」，界面能看见步骤；一篇 md 在写的时候能看见排版。

## 第 5 批 · 自动化变真

对着旧桌面的定时任务做。不做 Cursor 那种模板墙。

验收：能存一条、到点能补跑一次（旧契约：启动最多补一次）。

## 测法（每批都这样）

- 窗口默认隐藏。`WORKBENCH_SHOW=1` 只给人看。
- CLI：`up` / `goto` / `send` / `shot`，图进 `/tmp/perigee-workbench/`，不进 git。
- 要看页面可用 Chrome：优先隔离浏览器；Flyby 走已登录 Chrome 时不要把窗抢到前台。
- 不 commit，除非李研点名。

## 失败就停

- 公司页留着只换商标 → 停，先砍。
- 第 2 批接不上 Grok 却假装会回 → 停，回到诚实提示。
- 去仿 Grok Bot 云电脑 → 不做。
