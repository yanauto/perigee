## packages（后端能力）

| 包 | 路径 | 职责 | 备注 |
|----|------|------|------|
| **event-schema** | `packages/event-schema` | 会话事件 v2、ErrorCode、`extractPathsFromToolArgs` | 契约源 |
| **engine-protocol** | `packages/engine-protocol` | `AgentEngine` 接口 + `StubEngine` | 可替换引擎 |
| **engine-grok-acp** | `packages/engine-grok-acp` | **主路径**：`grok agent stdio` + JSON-RPC ACP | 一会话一长活进程 |
| **engine-grok-build** | `packages/engine-grok-build` | **降级**：`grok -p --output-format streaming-json` | 超时 / 进程组 kill |
| **host-core** | `packages/host-core` | Session / EventBus / FS / Diff / Approval / Settings / Transcript / SessionStore / diagnostics | 可单测 |
| **md-core** | `packages/md-core` | Markdown → HTML + TOC | 纯函数 |

## 数据流（当前架构）

```text
Renderer (Kimi)
    │  window.perigee
    ▼
preload (CJS · sandbox)
    │  IPC 白名单
    ▼
main · createEngine(settings)
    │
    ├─ engineMode=acp ──────► GrokAcpEngine ──► 子进程: grok agent stdio
    │                              │                 JSON-RPC + session/update
    ├─ engineMode=headless ─► GrokBuildEngine ─► 子进程: grok -p streaming-json
    │   (或 acpFallback)
    └─ engineMode=stub ─────► StubEngine
                │
                ▼
         host-core EventBus / Diff / Approval / Transcript
                │
                ▼
         session:event → Renderer
```

| settings 字段 | 作用 |
|---------------|------|
| `engineMode` | `acp`（默认）· `headless` · `stub`（`grok-build` 别名→headless） |
| `permissionPolicy` | `yolo` / `ask`（真审批需 ACP） |
| `acpFallbackHeadless` | ACP 不可用时是否回退 -p |
| `maxParallelSessions` | 并行会话上限（默认 5） |
| `turnTimeoutMs` | headless 单回合超时 |
