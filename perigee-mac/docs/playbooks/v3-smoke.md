# v3 手测剧本（T004 验收用；T009 后含首页/侧栏章节 §J）

> 对应纲领 §6 验收清单。每条给操作与预期。
> 前置：`pnpm install && pnpm dev` 起窗；建议先开一个有 `.md` 与 git 改动的真实工作区。
> 主题默认暗色；浅色单独一轮（§F）。
> T009 变更：启动第一屏 = 首页；⌘N = 去首页聚焦输入框（会话在首页发送时才创建）；侧栏不再按状态分组。

## A. 布局与信息架构

1. 起窗 → 第一屏为**首页**（§J）；点任意会话 → 三栏工作视图：左栏会话列表 / 中栏对话流 + Composer / 右栏默认收起。
2. ⌘` → 底部终端抽屉 200ms 内滑出；再按 ⌘` 收起。
3. 点 chat 头右侧「上下文面板」图标 → 右栏打开，默认「文件」tab；Esc → 关闭。
4. 右栏 tab「文件」「Diff」互斥切换，同一时刻只有一个内容视图。

## B. 键盘流（纲领 §3 逐条）

| 键 | 操作 | 预期 |
|---|---|---|
| ⌘K | 按 ⌘K | 统一命令面板打开；输入模糊串可同时命中命令/Slash/会话/文件四类；↑↓+Enter 执行 |
| ⌘N | 按 ⌘N | 去首页并聚焦大输入框（T009 起会话在首页发送时才创建） |
| ⌘1…⌘9 | 按 ⌘1 / ⌘2 | 切到侧栏顺序第 1/2 个会话（与侧栏 kbd 提示一致） |

## C. 三态与 tooltip 抽查（任选 10 个可交互元素）

候选：侧栏会话行、侧栏行内删除钮、chat 头 6 个图标钮、Composer 发送钮、权限段控件、模型 chip、slash 菜单项、工具调用行、turn 摘要「打回此轮」、右栏 tab、终端头图标钮。

每个检查：hover 有底色变化（120ms）→ 按下有 active 态 → Tab 聚焦有 accent 焦点环 → 图标钮悬停 400ms 出 tooltip。

## D. 对话流与 T001 流式回归

1. 发一条长回复请求（如「写 500 字介绍」）→ 文字**即时逐段上屏**，无整段蹦出。
2. 有思考输出时 → 思考块 streaming 中自动展开，结束后可折叠。
3. 滚动到中部后新 delta 到达 → 不强制吸底；回到底部 80px 内 → 恢复粘底。
4. 工具调用默认单行（图标+名称+目标+状态点）；点击行内展开参数/结果；点行尾图标在右栏查看。
5. 用户消息出现前无大卡片，只有细线轮次分隔。
6. turn.summary 渲染为轻量行内条：+N−N、文件 chips（可点开文件）、「查看变更」开右栏 Diff、「打回此轮」二次确认后磁盘还原。

## E. 右栏单实例（T003 回归）

1. 从对话路径 chip 打开 `A.md` → 右栏文件视图。
2. 再从文件树点 `B.ts` → **同一面板同一视图**替换为 B.ts，无第二个文件窗口。
3. 再从工具行打开工具详情 → 再点文件树 C 文件 → 仍只有一个视图实例。
4. .md 默认渲染视图，可切编辑；⌘S 保存；脏标记（黄点）显示与消失正确。

## F. 浅色主题（与暗色同标准）

1. 设置 → 主题 → 浅色；或 ⌘K「切换暗色/浅色」。
2. 全量过 A–E 关键路径一遍：文本可读（正文不灰雾）、accent 一致、焦点环可见、diff 红绿可辨。
3. 切回暗色，无样式残留。

## I. T005/T006 桥回归（T007 点亮项）

1. 左栏「CLI 会话」组：列出 title/时间/cwd；点击 → 恢复到 Desktop（ACP session/load），历史消息（用户/思考/助手/工具）正确渲染成对话流，随后可正常续聊。
2. `/` 菜单：内建命令置顶；/rewind 置灰「引擎暂不支持」，无假按钮。
3. `/effort low`、`/mcps list` 选中即执行，结果反馈（hint/banner）可见，命令不作为聊天消息发出。
4. ⌘K 输入 slash 名 → Slash 组条目可执行（非「桥接中」）。
5. 剪贴板有图时 ⌘V → 附件 chip；会话有用量时 Composer 小字显示窗口占比（如 18.9k / 500.0k · 4%）。
6. headless 引擎模式下：CLI 会话组保持置灰并注明「ACP 模式专用」。

## H. 健壮性

1. 未打开工作区：空态引导「打开文件夹」，Composer 禁用，不报错。
2. 会话流式中切会话再切回 → 流式块不丢、不错位。
3. 删除会话二次确认；重命名行内编辑 Enter/Esc。
4. 引擎 stub 模式下全 UI 可用（settings.engineMode=stub 回声）。

## J. 首页与侧栏（T009）

1. **启动落首页**：起窗第一屏 = 首页（问候语 / 用量仪表盘 / 居中大输入框 / 需要你与未读行），限宽居中不满铺。
2. **红绿灯无重叠**：macOS 红绿灯区与工作区切换器互不遮挡；顶栏空白处可拖拽窗口，按钮区不可拖。
3. **首页发送**：输入文字 Enter → 自动新建会话并进入对话视图，消息正常流式回复。
4. **⌘N**：任何界面按 ⌘N → 回首页且输入框已聚焦；不产生空会话。
5. **仪表盘**：范围切 All/30d/7d 数据随之变化；Overview/Models 两 tab；热力格 hover 有「date · N tokens」；样本不足的维度不显示。
6. **侧栏统一列表**：无「空闲/已完成」等状态分组；Desktop 与 CLI 会话混排，CLI 行尾有小 `CLI` 徽标；同一会话不出现两次。
7. **四态点**：working=灰点呼吸 / needs_input=accent 点闪烁 / unread=绿点常亮 / read=暗灰点；点开 unread 会话后圆点变 read（已读真实持久）。
8. **自定义分组**：「+ 新建分组」命名 → 拖会话行到组头 → 点击组头折叠 → 双击名称重命名 → hover 删除（组内会话回未分组）；**重启 App 后分组与归组保留**。
9. **间距抽查**：首页任意相邻大区块间距 ∈ {8, 16, 24}px 档位（DevTools 量 .home-col gap=24、卡片 padding=16）。
