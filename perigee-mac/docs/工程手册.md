# perigee 工程手册

> 稳定知识：接口、环境、坑。易变进度看 `vitals proj now grok-desktop`。

## 环境

| 项 | 值 |
|----|-----|
| 根目录 | `~/projects/perigee/perigee-mac` |
| Node | ≥ 20 |
| 包管理 | pnpm 10+ |
| 平台 | macOS Apple Silicon（首发） |
| Grok CLI | `~/.grok/bin/grok`（OAuth 在 `~/.grok/auth.json`）；升级：`grok update --check` / `grok update --stable` |
| 上游源码 | `vendor/grok-build` ← `https://github.com/xai-org/grok-build`（`./scripts/sync-grok-cli.sh`） |

## 常用命令

```bash
pnpm install
pnpm dev                                          # 开发起窗
pnpm run doctor
pnpm test
pnpm --filter @perigee/app run typecheck
pnpm --filter @perigee/app run build
pnpm --filter @perigee/app run rebuild:native  # pack 前必做：node-pty
pnpm --filter @perigee/app run pack          # → release/mac-arm64/*.app
# 安装到 Applications：docs/playbooks/install-macos.md
./scripts/sync-grok-cli.sh                        # 拉最新 grok CLI 源到 vendor/
./scripts/rebuild-native.sh
```

## 运行时路径

| 用途 | 路径 |
|------|------|
| 用户设置 | `~/Library/Application Support/@perigee/app/settings.json`（或 Electron userData） |
| 工作区最近列表 | 同上目录 `app-state.json` |
| 会话 transcript | userData `transcripts/*.jsonl` |
| 会话元数据 | userData `sessions-meta.json`（含 lastReadAt / lastActivityAt） |
| **用量总账（T011）** | userData `usage-ledger/YYYY-MM.jsonl` + `.migrated-v1` |
| UI 状态桶 | userData `ui-state.json` |

### 用量数据口径（T008 / T011）

| 指标 | 来源 | 说明 |
|------|------|------|
| **totalTokens / daily.tokens / byModel.tokens** | **`usage-ledger`** | ACP `usage` 事件只追加入账；`eventId` 幂等；**删除会话不改账本** |
| messages | Desktop transcript `user.message` + CLI `signals.userMessageCount` | 删会话会少计 Desktop 消息数（token 仍在账本） |
| sessions | Desktop meta + CLI summary（resume UUID 去重） | — |
| CLI tokens | **不计入** lifetime | `signals.contextTokensUsed` 是当前窗口占用，禁止当总账 |
| 历史估算 | **不做** | 仅迁移 Desktop 真实 `usage` 事件进账本 |

## 引擎协议（摘要）

### 主路径 ACP（默认 `engineMode=acp`）

```bash
GROK_CLIENT_VERSION=perigee/0.3.0 grok --no-auto-update agent stdio
# JSON-RPC: initialize → authenticate → session/new {cwd, mcpServers:[]} → session/prompt
```

实现：`packages/engine-grok-acp`（握手纯函数 `handshake.ts`）。握手实录：`docs/fixtures/acp-handshake.md`。

grok 1.0 扩展通知（`subagent-map.ts`）：`queue/changed`、`sessions/changed`、`models/update`、`mcp_initialized`、`mcp/servers_updated` → lifecycle；侧栏 CLI 名册 / 模型 chip / MCP 计数据此刷新。不接 ACP `terminal/*`（Perigee 用 node-pty）。

`initialize` 必须带 `_meta.clientType=perigee`、`startupHints.nonInteractive`，并在 `authMethods` 非空时立刻 `authenticate`（优先 `defaultAuthMethodId` / `cached_token`，`_meta.headless=true`）。这是 grok 1.0 官方嵌入路径；跳过 authenticate 在旧版偶发能通，1.0+ 不再当作合法客户端。

对照本机 CLI：`grok --version`（2026-08-13 实测 stable **1.0.3**）。vendor 源码用 `./scripts/sync-grok-cli.sh` 拉到 `vendor/grok-build`（只读）。

### 降级 Headless

```bash
grok -p "<prompt>" --cwd <ws> --output-format streaming-json --always-approve --max-turns 30
```

实现：`packages/engine-grok-build`（超时 / 进程组 kill）。  
`acpFallbackHeadless=true` 时构造 ACP 失败会回退。

## 关键坑

1. **preload 必须 CJS**（`index.cjs`）。ESM + sandbox → 黑屏。  
2. electron-builder 打包后也要验 `.app`，不能只验 `pnpm dev`。  
3. **安装到 /Applications**：先 `rebuild:native` 再 `pack`；`xattr -cr` 清 quarantine；勿 `pkill -f "Perigee"`（会误杀含该字样的 shell）。  
 
3. `pnpm doctor` 是 pnpm 内置命令；本项目自检用 **`pnpm run doctor`**。  
4. workspace 包勿被 externalize 到未编译 dist；electron-vite 用 alias 指到 `packages/*/src`。  
5. **app-region 拖拽区不得与可点元素重叠**（T024）：`no-drag` 挖洞只对 drag 祖先内子节点可靠，盖在整栏 drag 上面的兄弟浮层挖不穿——命中在 Electron 原生窗口层、Chromium 之前。设计上用「拖拽区分段绕开可点元素」（现行 `.ch-left-drag/.ch-toggle-safe/.ch-drag-fill` 三段式）。**CDP/合成鼠标事件走 Chromium 管线，测不出原生拦截**——此类问题只认真机鼠标或系统级注入的证据。  
6. **`::after` 全局留给 `[data-tip]` tooltip**（T016 返修 2 / T026 返修）：组件伪元素一律用 `::before` 或真实子元素；tooltip 规则与组件 `::after` 同特异度会互相渗透（Switch 旋钮穿模、`.sb-toggle` 悬停区两案）。tooltip 常驻布局（`opacity:0` 非 `display:none`），侧栏内已封顶 200px 且禁 `data-tip-pos="right"`（有契约测试）。  
7. **UI 测量-写回要防自激环**（T023 返修）：凡「量容器 → 写样式/viewBox」链路，写回值不得再影响被量对象（图表零测量、高度纯函数化 `chart-metrics.ts`）；SVG 只给 viewBox 不锁高时渲染高=宽×比例，会反向撑容器。  
8. **UI 铁律测试化**：拍板过的观感铁律（侧栏零横向滚动、组头箭头朝向、样式块唯一、发送/停止互斥）写成 vitest CSS/源码契约（`sidebar-overflow.test.ts`、`group-chevron.test.ts` 等），回退即红，不靠人肉记忆。  
9. **界面语言**：默认 **en**（无 localStorage / 无 uiState 时）。`lang.pref` 以本 renderer 的 `localStorage` 镜像为准，陈旧 `uiState` 不得把界面打回中文（`i18n/lang-pref.ts`）。已选中文的用户不受影响。  
10. **正式 .dmg**：用户从 [GitHub Releases v0.3.0](https://github.com/yanauto/perigee/releases/tag/v0.3.0) 下；自己打：`rebuild:native` 后 `pnpm --filter @perigee/app run dist`（未签名 `identity: null`）。
